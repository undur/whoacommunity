Deploying with Apache and modulo reference draft

A reference comparison, not the recommended path — the field-tested guide is Pure Modulo. See also Apache with mod_WebObjects, the classic.

The hybrid: Apache keeps ports 80 and 443 — TLS via certbot, virtual hosts, static files — and modulo stands behind it as the WO-aware reverse proxy, replacing mod_WebObjects without compiling an Apache module. Instance routing, session affinity, failover and WebSocket tunneling come from modulo; certificates, hostnames and redirects stay Apache's to manage, the way they always were.

When would you want this? An existing Apache estate you can't (or won't) retire, or an organization that requires Apache at the edge. Everything Apache-related below — the vhost files, the per-site rewrites, the certbot runs and its renewal timer — is work the pure stack does for you from one TOML file.
