Setting up a deployment server

The guide below is the setup script — setup-server.sh from the modulo repository, rendered with its comments as the narrative. Running it from your workstation gives you a server running the whole stack — wotaskd, JavaMonitor and modulo — serving its own admin dashboard over a real certificate, ready for apps. Read it here; run it from there:

curl -O https://raw.githubusercontent.com/undur/modulo/main/scripts/setup-server.sh
chmod +x setup-server.sh
./setup-server.sh myserver.example you@example.com
